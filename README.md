🤖 ZESR Movie Bot

A WhatsApp multi-device bot built with Node.js + Baileys.

✨ Features

- 🎬 Movie & TV downloads
- 📺 Sinhala cartoons
- 🎵 TikTok / Instagram tools
- 👀 View Once (.vv)
- 📤 Forward messages
- 🎥 Video Note
- 👥 Group tools
- 🛡️ Anti Status Mention
- 🔗 Pairing system
- 👑 Owner / Creator commands
- ⚡ Auto reconnect
- 📊 Bot status & runtime

🛠️ Tech

- Node.js
- Baileys
- Express
- MongoDB
- Axios

🚀 Setup

npm install
npm start
